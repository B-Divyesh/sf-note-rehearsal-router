See what the extension stores

Your notes, filenames, folder paths, and routing history stay on your device.

Folder access

You choose one local folder through Chrome’s folder picker. The extension reads Markdown files there and writes separate ticket files. It does not change source notes or request access to web pages.

Browser storage

The extension stores the chosen folder handle, routing ledger, preferences, license, and cached license result in its browser storage. The demo uses a separate key that starts with demo:.

Network requests

The free workflow sends no note data to a server. License verification sends only the license token to Sociobot’s billing API. The website and extension have no analytics, advertising, trackers, or remote fonts.

Payments

Sociobot / Dodo handles checkout, receipts, and refunds as the merchant of record. The product does not receive card details.

Export and deletion

You can export the routing ledger from the extension. “Forget local data” clears browser-held state. It does not delete ticket files already written to disk. After uninstalling, manage any remaining ticket files in your notes folder.

Questions

Use the support contact on your purchase receipt or open an issue in the public source repository.
