Five actions

Choose one action for each note

The extension waits for your choice. It does not choose or summarize for you.

  1. 1

    Recall

    Retrieve the central idea without looking, then check the gaps.

  2. 2

    Solve

    Use the note on one concrete problem and show each step.

  3. 3

    Teach

    Explain it to a beginner with an example and a limitation.

  4. 4

    Do

    Take the smallest real step before reopening the note.

  5. 5

    Archive

    Record why the note no longer needs rehearsal.

How it works

Create one separate action ticket

  1. 1

    Choose a folder

    Use Chrome’s folder picker to select your Markdown notes.

  2. 2

    Route one note

    Read the excerpt and choose recall, solve, teach, do, or archive.

  3. 3

    Use the ticket

    The extension writes a separate Markdown ticket under .rehearsal/.

Privacy and limits

Your notes stay on this device

The extension reads only the folder you choose. It does not read web pages, upload notes, run analytics, or sync to a cloud database.
